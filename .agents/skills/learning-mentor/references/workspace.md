# 学习工作区与记录

在首次落地学习框架、更新进度或收尾时读取。技能只负责通用教学流程；领域目标、材料、课程和学员信息留在工作区，不复制进技能目录。

## 选择位置与最小结构

优先使用用户指定或会话已经选定的位置；已有框架沿用，不为统一模板迁移文件。当前项目已有 `learning/` 且领域相符时直接接续。新项目在已选定的可写工作目录下默认建立 `learning/`；位置不明确或会与其他领域记录混用时，只问一次放在哪里。

新框架最初只需：

```text
learning/
  README.md        学习约定、入口、调用方式
  ROADMAP.md       按依赖排列的阶段、近期成果、完成依据
  PROGRESS.md      当前状态与精确接续点
```

第一课准备好再写 `lessons/`，有实际作品再建合适的实践目录，有互动证据再写 `records/`。已有 `MENTOR.md` 可保留领域特定约定，不需要复制整份技能。简单学习可把首项任务直接写在 PROGRESS 中，不为每个问题建文件。

README 中记录目标是用户已明确、用户接受的建议，还是仍在讨论；标注相关对话日期或记录入口。长期方向、近期成果、观察进步的依据与已知约束须可找到。不把目标草案变成正式课程，也不因为背景信息不完整而禁止开始小探索。

推荐入口文案：新会话输入 `$learning-mentor`；已有学习会话说“继续”“提示”“检查作业”“复习”“收尾”即可。技能未被当前客户端发现时，提示重新加载技能或重开会话；不保证热加载已完成。临时可让助手读取该技能的实际路径。

## PROGRESS 的最少信息

沿用现有标题，按需补齐字段；不强制另建数据库、脚本或 JSON 状态机。

- 当前工作区/主题与目标状态；最近更新日期。
- 当前活动单元、所属主题和与阶段成果的关系；
- 当前主任务及材料路径，已经完成与仍未完成的部分。
- **接续点**：目前阶段（目标讨论/待预测/待实践/待解释/待反馈/待迁移/已收尾）、上一条待答问题或具体动作、已经给过的提示、导师下一动作。
- 学习者相关基础与约束，区分自述、实际观察和待验证。
- 能力状态、证据链接和重要不确定性。
- 复习项、触发时机或建议日期，以及下一步。

一个活动单元应能在若干回合内完成，并在课程文件中说明前置能力、学习目标、关键概念和不变量、定向阅读、受控实验、带支架实现、独立迁移、故障修复或项目连接、完成证据和延迟复习触发点。材料可以完整准备，但按学习者状态分层交付；材料读完不等于单元完成。

只有影响学习的环境信息才记录，例如编译器版本、教材版本、使用工具或任务条件。源码/资料版本与实践工具版本分别记，不能用教材版本冒充实际运行版本。

能力状态可用：待验证、接触过、提示下完成、独立完成、能够迁移、需复习；后续遗忘可标“需复习”而不删旧证据。评价具体能力，不给学生贴固定智力或学习风格标签。项目已经有等价状态时沿用。

## 证据记录

每次有实质学习互动，在已有当次记录中补充，或建立 `records/YYYY-MM-DD-NN.md`；编号避免覆盖。使用当天实际日期，不照抄模板示例。记录：

```text
单元 / 主题 / 本次目标：
学习者已有相关经验：
预测、理由和信心：
学生的预测、尝试或作品：保留必要原话/文件链接
实际观察：运行结果、推导步骤、作品反馈等
来源：学生自述 / 工具检查 / 导师示范 / 独立变式表现
反馈与提示：给了什么帮助，还有什么不确定
迁移与延迟复测表现：
目标或能力状态变化及理由：
未解问题、待答题和下一动作：
复习项与触发时机：
```

技术检查记录命令、目录、相关版本、关键结果和未验证范围；非技术任务保留足以核对判断的材料和评价依据。避免保存无关隐私、凭据或整段无用日志。

写入前检查文件现状，保留学生已有改动和历史证据。优先使用局部更新；有冲突先查明，不回滚整个工作区。完成后检查改动和引用能否定位。学生成果仍在变动时，记录关键片段或差异，不能只留下会漂移的文件链接就声称可复现。

## 不虚增、不丢失

- 只读恢复、重复“继续”、打开文档或导师跑通示例，不产生学员完成记录。
- 布置了新题但尚无回答时，仅保存接续点，不标完成；提示增加时保存提示程度。
- “我会了/做完了”记为自述；已有作品能检查就直接查看，缺证据时用一个小问题补足，而非索取完整报告。
- 相同证据不重复记为新成果。一次维护只更新实际变化的状态，不刷学习天数或累计分数。
- 即使没有说“收尾”，也保存已产生的重要证据与待答点，方便中断后恢复。没有新的内容时不造空日志。
- 收尾后不自动安排下一课为进行中；下次根据最近证据和用户状态恢复。
- 用户改目标时记录新目标及理由，保留原有成果和暂停点；不同领域不共用同一张能力表。
